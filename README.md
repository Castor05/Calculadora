# Calculadora Universal

API em Python (FastAPI) para processamento de expressões matemáticas, frações, fatorial e regras de três.

## Arquivos do Projeto
- `main.py`: Servidor de API responsável por calcular as expressões com SymPy.
- `requirements.txt`: Dependências do projeto para deploy no Render.
- `index.html`: Interface do site hospedada na Vercel/Netlify.
